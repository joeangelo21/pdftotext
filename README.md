# pdftotext

Uma ferramenta de automação desenvolvida em Python para extração eficiente de texto bruto a partir de arquivos PDF. 

Este utilitário foi desenhado para facilitar a ingestão de literatura técnica e documentação extensa, permitindo a conversão rápida para arquivos `.txt`, ideal para análise, tradução ou processamento por modelos de IA e ferramentas de segurança.

## 🛠 Funcionalidades
- **Automação de Lista**: Detecta e lista automaticamente todos os arquivos PDF presentes no diretório de execução.
- **Feedback em Tempo Real**: Exibe o progresso de processamento por página, garantindo controle sobre arquivos volumosos.
- **Tratamento de Exceções**: Identifica e sinaliza páginas contendo apenas imagens ou vazias, evitando interrupções na extração.
- **Output Estruturado**: Gera arquivos de texto limpos, com codificação UTF-8, prontos para uso em pipelines de dados.

## 🚀 Como utilizar

1. **Pré-requisitos**:
   Certifique-se de ter o Python instalado e a biblioteca `PyPDF2`:
   ```bash
   pip install PyPDF2
Execução:
Coloque o script estrator2.py no diretório onde estão seus arquivos PDF e execute:

Bash
python estrator2.py
Fluxo:
O sistema solicitará o nome do arquivo de origem (PDF) e definirá automaticamente o arquivo de destino (.txt).
